# 第三章 多道程序与分时多任务

## 功能总结

分析：
跟踪当前任务系统调用的历史信息。

支持3种信息跟踪：
（1）读取任务，指定地址id处的一个字节对应的无符号整数值并返回。

（2）将数据data写入用户程序id地址处，返回值为0。

（3）返回当前任务调用编号为id的系统调用次数

（4） 默认返回-1

## 问答题

RustSBI-QEMU Version 0.2.0-alpha.2

1. 正确进入 U 态后，程序的特征还应有：使用 S 态特权指令，访问 S 态寄存器后会报错。 请同学们可以自行测试这些内容（运行 [三个 bad 测例 (ch2b_bad_*.rs)](https://github.com/LearningOS/rCore-Tutorial-Test-2025S/tree/master/src/bin) ）， 描述程序出错行为，同时注意注明你使用的 sbi 及其版本。
    1. 第一个测试用例非法地址的写入。
        1. 内存地址在加载应用程序的时候已经分配好了，从linker.ld看到应用程序的起始地址高于0x0
        2. 与设计相关，可能0x0地址在riscv中有特殊作用，所以做了保护设计，触发了异常
    2. 错误的指令。从用户态执行了特权级别的指令sret
    3. 错误的寄存器。尝试在用户态下读取特权级别寄存器sstatus
2. 深入理解 [trap.S](https://github.com/LearningOS/rCore-Camp-Code-2025S/blob/ch3/os/src/trap/trap.S) 中两个函数 `__alltraps` 和 `__restore` 的作用，并回答如下问题:
    1. L40：刚进入 `__restore` 时，`sp` 代表了什么值。请指出 `__restore` 的两种使用情景。
       
        sp 寄存器 指向了被分配的内核地址。
        restore作用1：异常处理从内核态返回用户态。
        
        restore作用2：应用程序切换时需要保存上一个程序的上下文
        
    2. L43-L48：这几行汇编代码特殊处理了哪些寄存器？这些寄存器的的值对于进入用户态有何意义？请分别解释。
       
        ```bash
        ld t0, 32*8(sp)  # 从内核栈加载保存的 sstatus 值到 t0
        ld t1, 33*8(sp)  # 从内核栈加载保存的 sepc 值到 t1
        ld t2, 2*8(sp)   # 从内核栈加载保存的用户栈指针到 t2
        csrw sstatus, t0  # 将 t0 中的值写入 sstatus CSR
        csrw sepc, t1  # 将 t1 中的值写入 sepc CSR
        csrw sscratch, t2   # 将 t2 中的值写入 sscratch CSR
        ```
        
        分别处理了sstatus、spec、sscratch。
        
        sstatus: 记录中断前特权级别状态，帮助设置特权级别
        
        spec: 保存异常程序地址，帮助进入用户内容态时，可以从这个地址继续执行
        
        sscratch: 提供临时存储空间,方便切换级别保存一些临时栈指针
        
    3. L50-L56：为何跳过了 `x2` 和 `x4`？
        1. x2 对应 栈指针寄存器（sp）
           
            sp当前正在被用于访问TrapContext，不能直接恢复
            
        2. x4 对应线程寄存器 用户态无法使用
    4.  `__restore`：中发生状态切换在哪一条指令？为何该指令执行之后会进入用户态？
        
        sret，sp从sscratch中获取了用户栈指针
        
    5. L13：该指令之后，`sp` 和 `sscratch` 中的值分别有什么意义？
       
        ```bash
        csrrw sp, sscratch, sp
        ```
        
        两个寄存器值交换了，sp重新获取了用户栈指针
        
    6. 从 U 态进入 S 态是哪一条指令发生的？
       
        我理解是从下述指令发生，从13行这里开始存放了临时的用户栈指针，使用了S态才能使用寄存器sscratch
        
        ```bash
        13行 csrrw sp, sscratch, sp 
        ```
